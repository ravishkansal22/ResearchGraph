# ResearchGraph Documentation

Welcome to the ResearchGraph documentation tree.

## Documentation Map

```text
docs/
├── architecture/   # High-level system architecture and component designs
├── decisions/      # Architecture Decision Records (ADRs) tracking design choices
├── research/       # Scientific literature reviews, mathematical formulations, research notes
├── api/            # Backend API specifications, contracts, and schema documentation
├── dataset/        # Corpus curation methodologies, source notes, and schema definitions
└── development/    # Contributor guides, local setup, environment specs, and tooling
```

## Architecture Decision Records (ADRs)
Technical decisions are tracked in `docs/decisions/` using the standard ADR format:
- `NNNN-title.md`
- Context, Decision, Status, and Consequences.
